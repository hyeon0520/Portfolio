# Portfolio
## 👤About Me
AI와 로보틱스를 중심으로 다양한 프로젝트와 연구를 수행하고 있습니다.  
산업 전력 시계열 이상탐지 연구부터 강화학습 기반 로봇 핸드 제어, 생성형 AI 이미지·비디오 서비스 개발까지 경험했습니다.  
연구 결과를 논문과 학회 발표로 확장하고, 실제 서비스 및 로봇 시스템에 적용하는 과정에 관심이 있습니다.  
새로운 기술을 빠르게 학습하고 직접 구현하며, 아이디어를 실제 결과물로 연결하는 것을 목표로 합니다.
